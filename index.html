마곡 클럽 예약 방법

Step‑by‑Step

예약 필수 조건

  • 전화·문자 인증
  • 결제 수단 1개 이상
  • 연령 확인(만 19세 이상)

추천 시간대

  • 주중 22:00‑02:00
  • 주말 21:00‑03:00
  • 이벤트 전날은 20:00부터

주요 결제 수단

  • 신용카드
  • 실시간 계좌이체
  • 간편 결제(카카오·네이버)

예약 제한

  • 한인당 일일 2건 제한
  • 대규모 파티는 사전 협의 필요
  • 프라이빗 룸은 별도 계약

예약 전 체크리스트

1. 신분증 확인

클럽 입장은 신분증 제시가 필수이며, 복사본은 인정되지 않습니다.

2. 입장 인원 확인

예약 인원과 실제 인원이 일치하는지 미리 확인하세요.

3. 복장 규정

스포츠웨어·운동화는 제한될 수 있으니 사전 확인이 필요합니다.

4. 금연·음주 정책

전 구역 금연이며, 주류는 0도이상에서만 제공됩니다.

조건별 적합 클럽

대규모 파티를 계획 중이라면 ‘에코 라운지’를, 조용한 분위기를 원한다면 ‘노이즈 라운지’를 선택하세요.

음악 장르는 EDM·힙합·테크노 중 선택 가능하며, 사전 요청 시 DJ 라인업을 조정할 수 있습니다.

예약 흐름
  1. 사이트 접속 → 클럽 선택
  2. 날짜·시간 선택 → 인원 입력
  3. 결제 진행 → 확인 메일 수신
  4. 입장 전 신분증·QR 코드 제시

자주 묻는 질문

마곡 클럽을 사전에 예약해야 하나요?

대부분의 클럽은 입장 인원을 관리하기 위해 사전 예약을 권장합니다. 특히 주말과 이벤트 날은 필수에 가깝습니다.

예약 시 필요한 최소 인원은 얼마인가요?

클럽마다 차이가 있지만 보통 2명 이상부터 예약이 가능하며, 대규모 파티는 최소 10명부터 조건이 완화됩니다.

예약 취소는 언제까지 가능하나요?

대부분 24시간 전까지는 무료 취소가 가능하지만, 이벤트 티켓은 취소가 제한될 수 있으니 사전 확인이 필요합니다.

첫 방문자에게 추천하는 클럽은 어디인가요?

초보자라면 사운드와 조명이 균형 잡힌 ‘노이즈 라운지’를 추천합니다. 예약 흐름이 간단하고 분위기가 편안합니다.
